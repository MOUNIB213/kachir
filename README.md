# كاشير دزاد — DZ Cashier (Flutter)

تطبيق نقطة بيع جزائري يعمل **بدون إنترنت** (SQLite)، بواجهة عربية RTL وإنجليزية، بالدينار الجزائري.

## المميزات
- **البيع**: بحث سريع، شبكة منتجات، سلة، تعديل الكمية والسعر، تخفيض، زبون عابر أو مسجّل.
- **الباركود**: مسح بالكاميرا (أندرويد / iOS / ويب) + دعم قارئ USB (اكتب الباركود ثم Enter).
- **طرق الدفع**: نقدًا، بطاقة CIB، شيك، **كريدي (دين)** مع دفعة جزئية.
- **المخزون**: منتجات، فئات، سعر شراء/بيع، تنبيه مخزون منخفض (شارة على التبويب)، خصم تلقائي عند البيع.
- **الزبائن والديون**: رصيد كل زبون، تسديد الديون، مجموع الديون.
- **الفواتير**: HT / TVA (19% · 9% · 0%) / TTC، بيانات المحل (NIF, NIS, RC, AI)، حق الطابع اختياري، PDF بصيغة A4 أو **حرارية 80mm**، طباعة ومشاركة.
- **التقارير**: اليوم / 7 أيام / 30 يومًا / الكل — رقم الأعمال، الربح التقريبي، عدد الفواتير، الديون.

> الأسعار تُدخل **TTC** ويُستخرج منها HT و TVA تلقائيًا.
> نسبة حق الطابع قابلة للتعديل وغير مفعّلة افتراضيًا؛ تأكد من النسبة الحالية مع محاسبك قبل الاستعمال التجاري.

## التشغيل
```bash
flutter create . --platforms=android,ios,windows,web   # مرة واحدة لتوليد مجلدات المنصات
flutter pub get
flutter run
```

### خطوات مهمة
1. **خط Cairo للـ PDF العربي**: ضع `Cairo-Regular.ttf` و `Cairo-Bold.ttf` (من Google Fonts) في `assets/fonts/`. بدونهما يحاول التطبيق تنزيلهما من الإنترنت.
2. **أندرويد** — في `android/app/src/main/AndroidManifest.xml` أضف:
   `<uses-permission android:name="android.permission.CAMERA"/>` ، واجعل `minSdkVersion 21` على الأقل.
3. **iOS** — في `ios/Runner/Info.plist` أضف `NSCameraUsageDescription`.
4. **الويب** — شغّل مرة واحدة: `dart run sqflite_common_ffi_web:setup` لنسخ ملفات sqlite3 wasm.
5. **ويندوز** — يعمل SQLite عبر FFI دون إعداد إضافي.

## هيكل المشروع
```
lib/
  main.dart            نقطة الدخول والثيم واللغة
  db/database.dart     SQLite: منتجات، زبائن، مبيعات، ديون
  models/models.dart   النماذج
  state/app_state.dart السلة والحسابات والإعدادات
  services/invoice_pdf.dart  فاتورة PDF
  l10n/strings.dart    الترجمات عربي/إنجليزي
  screens/             البيع، المنتجات، الزبائن، المبيعات، الإعدادات، الماسح
```
